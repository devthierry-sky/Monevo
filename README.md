## Sobre o projeto

O **Monevo** é uma aplicação web de gerenciamento financeiro pessoal, desenvolvida com o objetivo de centralizar o controle de receitas, despesas e movimentações financeiras em um único lugar.

A plataforma busca oferecer uma experiência intuitiva, com um dashboard que apresenta informações importantes sobre a situação financeira, facilitando o acompanhamento e a organização do dinheiro.

O projeto também faz parte da minha jornada de aprendizado em desenvolvimento Full Stack, permitindo aplicar conhecimentos de desenvolvimento Front-End, Back-End, banco de dados e integração de APIs.

## Interface

O Monevo utiliza uma identidade visual baseada em um tema escuro, com elementos em azul para destacar informações e ações importantes.

## Objetivos do projeto

- Desenvolver uma aplicação Full Stack na prática.
- Aprimorar conhecimentos em React e JavaScript.
- Aprender a desenvolver APIs REST com Node.js e Express.
- Trabalhar com banco de dados relacional utilizando PostgreSQL.
- Aplicar boas práticas de organização e arquitetura de software.
